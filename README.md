# ⚡ NEXORA AI — Futuristic Premium AI Technology Platform

> **"Intelligence. Beyond Limits."**  
> A cutting-edge, futuristic AI company website built with semantic HTML5, cybernetic glassmorphism CSS3, and interactive JavaScript for the college Web Development Activity project.

---

## 🌌 Overview
**NEXORA AI** is an enterprise-grade artificial intelligence and neural computing platform inspired by world-class AI startups (OpenAI, Anthropic, Scale AI, Cursor, Linear). It showcases a dark-mode cyber aesthetic with electric blue and violet energy glows, an interactive 3D-like holographic AI Orb, and a live terminal neural playground.

## 🛠️ Tech Stack
- **HTML5:** Modern semantic markup (`header`, `nav`, `main`, `section`, `article`, `footer`).
- **CSS3:** Custom Properties (Variables), Flexbox, CSS Grid, 3D keyframe orbital animations, ambient glassmorphism blur filters.
- **JavaScript (ES6):** Real-time typewriter string streaming engine, modal state management, event listeners, and toast feedback.
